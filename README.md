# Narcis

Osobní progress journal – nová verze, stavíme od začátku krok po kroku.

## Stará verze

První verze (Gym: tréninky, plány, partie, fotky, progres) je uložená v gitu pod štítkem `stara-verze`.

Zobrazit, co v ní bylo:

```
git show stara-verze --stat
```

Vytáhnout z ní jeden soubor (třeba hlasový zápis):

```
git checkout stara-verze -- js/spoken-entry.js
```
